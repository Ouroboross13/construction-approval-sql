# Construction Approval Workflow Analytics (Oracle DB)

SQL-артефакты для аналитической подсистемы мониторинга строительства. 
Проект решает прикладную задачу: визуализация узких мест в согласовании строительных заявок от подрядчиков и подготовка витрин данных для руководителей.

## О проекте
В процессе строительства объекты и этапы работ требуют согласования с кураторами, сметчиками и техническим надзором. 
Данный проект содержит:
1. **Реляционную модель:** связь подрядчиков, заявок и истории этапов согласования.
2. **Аналитические витрины:** представления (Views) для карточек заявок.
3. **Оптимизацию:** структуру индексов под регулярные фильтрации и джойны (подтверждено через EXPLAIN PLAN).
4. **Скрипты контроля целостности:** проверка задвоений при джойнах и поиск дубликатов этапов.

## Структура репозитория
* `db/schema.sql` — DDL-скрипт (Oracle: NUMBER, VARCHAR2, DATE) с внешними ключами и составными индексами.
* `db/views.sql` — View для карточки заявки с денормализацией данных.
* `db/queries.sql` — рабочие запросы (INNER/LEFT JOIN, фильтрация последнего статуса, агрегации с CASE, Data Quality проверки).
